# ⚡🚗 Electrical Vehicles

This project focuses on analyzing the global adoption and infrastructure growth of Electric Vehicles (EVs) using real-world data from open sources such as [OpenChargeMap API](./https://openchargemap.org/site/develop/api)

The main objective is to:

- Understand spatial, economic, and demographic factors influencing EV adoption.

- Analyze charging station infrastructure and its global distribution.

- Build predictive models to forecast future trends in EV adoption and station deployment.

## ⚙️ Installation

Clone the repository:

```bash
$ git clone https://github.com/danaelshrbiny10/Electrical-Vehicles.git
$ cd Electrical-Vehicles
$ python3 -m venv .env
$ source .env/bin/activate
```

Set up environment variables:

```bash
$ cp .env.example .env
```

## :snake: Python Requirements

Within your preferred Python environment, run the following to set up the project:

Using `pip`

```bash

$ pip install -r requirements.txt
```

Using `Makefile`

If a Makefile is provided, you can install dependencies with:

```bash
$ make install
```
